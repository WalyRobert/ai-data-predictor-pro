# Segurança e dados

Este é um protótipo educacional que processa arquivos no navegador. Não publique datasets pessoais, credenciais ou documentos reais como exemplos. Não há serviço de upload ou chamadas de IA externas nesta edição.

Dependências são fixadas no lockfile; limites de entrada reduzem consumo, mas não são uma sandbox. Evite arquivos XLSX não confiáveis e mantenha dependências atualizadas. O projeto não deve fundamentar decisões sobre pessoas ou aplicações críticas sem validação apropriada.

Ao relatar um problema, use um exemplo sintético mínimo e não inclua dados sensíveis em issues públicas.
